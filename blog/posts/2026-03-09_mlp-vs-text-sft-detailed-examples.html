Key Observations

1. SFT is essential. Base models (no fine-tuning) produce empty or incoherent outputs (BLEU ~0.003). Both SFT approaches achieve 80-100× improvement.

Where MLP (ESM-3 embeddings) wins

  • Function description: ROUGE-L 0.458 vs 0.292 (+57%). ESM-3 embeddings capture structural/functional signatures that help predict protein function, membrane insertion roles, and ribosomal activities.
  • Conciseness: MLP outputs are typically shorter and more focused. Text SFT frequently appends hallucinated paragraphs about unrelated proteins.
  • Fewer hallucination cascades: When MLP is wrong, it's wrong briefly. Text can spiral into 200+ word confabulations.

Where Text wins

  • Catalytic activity: BLEU 0.367 vs 0.313. Text correctly identifies more chemical reactions, possibly because specific substrate/product names are more easily memorized from raw sequence tokens seen during training.
  • General knowledge: BLEU 0.350 vs 0.278. Text is better at protein family classification for proteins with clear sequence signatures (e.g., phosphoribosyltransferases, detoxification proteins).

Where both are equal

  • Easy tasks: Protein naming (L6, uL18), family identification (Fis, uL18), and well-characterized viral proteins. Both achieve BLEU >0.7.
  • Domain prediction: Both around ROUGE-L ~0.42. Remains the hardest category overall.

Where both struggle

  • Complex/rare outputs: Quaternary structure, subcellular localization details, expression conditions. Neither approach handles these well.
  • Regulatory functions: Both default to enzymatic activity predictions, reflecting training data bias.
  • Short/unusual proteins: Proteins <150 aa with rare functions confuse both models.

Text verbosity problem: Text SFT outputs are systematically longer than MLP outputs, especially when the model is uncertain. On wrong answers, Text averages ~3× longer responses with hallucinated protein interactions, unrelated functions, or fabricated evidence codes. This suggests ESM-3 embeddings provide a stronger "grounding" signal that prevents output drift.

Conclusion

At comparable training compute, MLP SFT produces more reliable, concise outputs with a large advantage on function descriptions (+57% ROUGE-L). Text SFT has a slight edge on catalytic reaction identification. The most striking qualitative difference is output length control: MLP rarely hallucinates beyond the expected answer format, while Text frequently produces verbose, cascading outputs.

For a protein understanding model, the MLP approach (ESM-3 embeddings + projector) appears to be the stronger foundation, with function prediction being the clearest differentiator. However, the Text approach's catalytic activity strength suggests that raw sequence tokens carry complementary information — a potential argument for hybrid approaches in future work.
