Executive Summary

As of March 16, 2026, the project has run 3 SFT and 14 GRPO experiments across 2 approaches (ESM3+MLP, Text-only). SFT results are clear: MLP achieves eval_loss 0.361 vs Text-only 1.207 (3.3x better, p<0.000001). GRPO results reveal a paradox: despite MLP's superior SFT loss, Text-only achieves higher GRPO reward on structure quality (0.832 vs 0.774, p=0.0005). The frozen-multimodal configuration partially closes this gap (0.774 mean_reward). The Perceiver path never completed training. 9 of 14 GRPO runs completed successfully; the remainder were early-stopped or interrupted.

2d. ProteinLM-Bench GRPO (Mol-Instructions Task)

ProteinLM-Bench GRPO shows flat/declining reward.
Run 1: mean_reward 0.695 (flat) | Run 2: 0.676 (declining -7.9%)
High zero-std fraction (37-42%) indicates many sample groups have identical rewards — weak learning signal.
Completion length is very short (~9 tokens), suggesting the model is not generating meaningful text.

2e. Frozen-MM and Classify Configurations

Frozen-MM configuration partially fixes MLP gradient death.
By freezing projector+pooling during GRPO, LoRA gradients become non-zero (0.071-0.119), enabling format learning.
Best frozen-MM reward: 0.774 (vs 0.582 for standard MLP with dead grads). A 33% improvement.
Frozen-MM+Focal variant reaches 0.725 with strong improvement trajectory (+60.6%).
Classification (binary) format shows mixed results.
MLP classify: 0.598 mean_reward but with strong +70.2% improvement trajectory.
Text classify: 0.710 mean_reward, but high zero-std fraction (58%) is concerning.
Binary format produces lower absolute rewards but more stable training dynamics.

3. Embedding Quality Analysis

Training the MLP projector does NOT improve biological clustering.
kNN@5 accuracy: Raw ESM3 = 54.2%, Trained MLP = 54.1%, Random MLP = 54.3%.
CKA similarity: Trained ↔ Random = 0.053 (very different representations, same downstream accuracy).
Consistent with ACL 2024, VIRAL 2025, CVPR 2024 multimodal literature. Novel finding for protein domain.

7. Recommendations

  1. Resume MLP+Thinking SFT — eval_loss 0.613 at only 500 steps is very promising. Run to completion for fair comparison.
  2. Run Perceiver SFT — the four-way thesis (Text/MLP/Perceiver/Flamingo) needs this data point. Priority experiment.
  3. Investigate MLP LoRA gradient death in GRPO — standard MLP configurations suffer from zero LoRA gradients. The frozen-MM workaround helps but doesn't fully solve the problem.
  4. Try GRPO structure with Text + more steps — the best text run (0.832) was still improving at end of training. Longer training could push higher.
  5. GRPO on GO prediction and stability tasks — all GRPO runs so far are structure-quality only. The downstream pipeline supports GO prediction and stability/ddG tasks.
  6. Evaluate GRPO checkpoints on held-out benchmarks — reward during training may not reflect true generalization. Need held-out eval.
  7. Explore why SFT advantage doesn't transfer to GRPO — MLP has 3.3x better SFT loss but worse GRPO reward. This is the central research question to resolve.
