Figure Style Audit: 3 of 6 Scripts Converted to Unified Module

Date: 2026-03-09  |  Question: How consistently do plotting scripts use the figure_style.py module?  |  infrastructurearchitecture

Executive Summary

Of the 6 plotting scripts in the project, 3 have been fully converted to use the centralized figure_style.py module (plot_pub_figures.py, plot_training.py, plot_schematic_overview.py). The remaining 3 are archived legacy scripts (blog/data/03-04/analysis_plots.py, blog/data/03-06/analysis_plots.py, blog/data/03-07/pub_figures.py) that still contain 100+ lines of hardcoded style definitions. The analyst agent spec (.claude/agents/analyst.md) has not been updated to reference figure_style.py and still prescribes the old inline approach with APPROACH_COLORS["text"] = "#2ca02c" (green), which conflicts with the canonical #808080 (gray) defined in the module.
