1. Summary

We ran the first production GRPO training on ProteinLMBench—a multiple-choice benchmark of 849 protein science questions—starting from our best ESM-3 + MLP SFT checkpoint on Qwen3-8B. The run completed 3 epochs (~40 steps) in about 12 minutes on 8xH100.

The headline result GRPO successfully taught the model to use <answer> tags (format compliance 85% → 94%), but factual accuracy on multiple-choice questions did not improve. Eval reward was flat at ~0.45 across all checkpoints. The model answered the same probe questions identically at steps 10, 20, and 30.

This is a meaningful negative result: it confirms that factual recall tasks benefit from SFT, not RL. GRPO optimizes how the model formats its answers, but cannot inject new knowledge about protein biology.

4. Probe Completions: Same Answers, Every Step

We tracked the model's responses to 5 fixed probe questions across steps 10, 20, and 30. The result was striking: the model produced identical answers at every checkpoint, getting 3 out of 5 correct each time.

What the probe tells us The model's factual knowledge is frozen in place from SFT. GRPO's policy gradient updates are too weak (or the reward signal too sparse) to shift which answer the model selects for any given question. The only behavioral change is surface-level: better formatting with <answer> tags.

This is consistent with what we know about RL fine-tuning: GRPO can reshape the model's output distribution (how it answers) but does not teach new facts (what it knows). For a multiple-choice task where the answer is either right or wrong, there is no continuous reward gradient for GRPO to follow toward better answers.

5. Analysis: Why GRPO Did Not Improve Accuracy

5.1. SFT Already Captured the Learnable Knowledge

The parent SFT model was trained on 4.89M protein instruction samples. Whatever protein science knowledge can be extracted from instruction tuning, the SFT run already captured it. GRPO cannot conjure new factual knowledge—it can only redistribute probability mass over existing model capabilities.

The ceiling problem: If the SFT model gets 3/5 probe questions right, GRPO can only improve by shifting probability mass from wrong answers to right ones. But the reward signal (binary right/wrong on 849 questions) provides almost no gradient information about why an answer is wrong or how to fix it.

5.2. The Dataset Is Extremely Small

ProteinLMBench has only 849 training questions. With a batch size of 4, gradient accumulation of 2, and 8 GPUs, each epoch is roughly 13 steps. Three epochs give ~40 total optimization steps—far too few for RL to discover meaningful policy improvements.

For comparison, successful GRPO runs in the literature (DeepSeek-R1, Qwen3) typically involve thousands to tens of thousands of optimization steps over large datasets. Our 40-step run is orders of magnitude below this threshold.

5.3. Binary Reward = Sparse Signal

Multiple-choice questions produce a binary reward: 1.0 for correct, 0.0 for incorrect (plus the 0.1 format bonus). This creates an extremely sparse reward landscape. GRPO's group-relative advantage computation subtracts the group mean, so within a group of 8 completions for the same question, the advantage is meaningful only if some completions are correct and others are wrong.

With temperature 0.9, the model often generates the same answer across all 8 group members—especially for short MC responses (~8 tokens). When all completions in a group get the same reward, the advantage is zero and that step contributes no gradient signal.

5.4. ESM-3 Encoder Was Unused

ProteinLMBench questions are purely textual—they ask about protein concepts, not about specific protein sequences. The ESM-3 encoder and MLP projector received zero gradient throughout training (grad_mm=0.0). This is expected behavior, but it means we are effectively running text-only GRPO despite using the esm3 approach.

6. Takeaways

Key findings from this experiment
  1. GRPO improves format compliance, not factual accuracy. The model learned <answer> tags (85% → 94%) but did not change which MC option it selected for any probe question.
  2. SFT is the right tool for factual recall tasks. Multiple-choice protein science questions are a knowledge retrieval problem. RL adds nothing when the bottleneck is what the model knows, not how it expresses it.
  3. 849 questions is far too few for meaningful RL. ~13 steps per epoch, ~40 total steps, binary reward—the optimization landscape is too sparse and too short for GRPO to find a signal.
  4. This is a meaningful negative result. It validates our hypothesis that RL should be applied to generative tasks with continuous reward signals (structure quality, stability prediction), not factual MC benchmarks.
  5. The format reward works as designed. The +0.1 bonus for <answer> tags is the only component that showed clear learning, confirming that GRPO can optimize surface-level formatting even when deeper accuracy is out of reach.

Where GRPO Should Show More Value

The theoretical advantage of GRPO over SFT is in tasks where:

  • Reward is continuous, not binary—e.g., pLDDT scores (0–100), F1 scores (0.0–1.0), MAE for stability predictions
  • Output is generative, not retrieval—e.g., describing protein structure quality, predicting GO terms, explaining stability effects
  • Multiple valid outputs exist—group diversity provides meaningful advantage signal
  • Dataset is large enough—thousands of questions with varied difficulty levels

Structure quality prediction with ESMFold rewards is the most promising candidate: the reward is continuous (pLDDT correlation), the output is generative (quality descriptions), and the model's protein encoder is actively engaged.
