1. Summary

We ran matched GRPO experiments on the structure quality task (ESMFold reward) comparing Text-only and ESM3+MLP approaches. Text achieves 0.83 mean reward vs MLP's 0.58, with 100% format compliance vs 74%. But the Text model's high reward comes from copying system prompt templates verbatim — "Strong hydrophobic core, regular secondary structure" appears identically for every protein, regardless of actual sequence properties.

Key finding: GRPO reward is gameable by template copying

The Text model achieves high structure quality reward by memorizing and replaying the example reasoning pattern from the system prompt. It never inspects the protein sequence. The MLP model generates original, protein-aware reasoning from ESM-3 embeddings — but a gradient flow bug prevents its LoRA weights from learning the output format.

3. Reward Curves

The Text model shows a clear upward trend from 0.63 (step 5) to consistently above 0.85 after step 30. The MLP model flatlines around 0.58–0.62 throughout training with no improvement trend.

Eval rewards confirm the pattern: Text improves from 0.75 → 0.80 → 0.84 across evaluations at steps 25/50/75, while MLP fluctuates between 0.46–0.54 without clear improvement.

5. Format Rate & Loss

The format rate gap is a downstream consequence of the gradient flow bug (Section 7). The MLP model cannot learn to reliably produce the <answer>...</answer> wrapper because its LoRA gradients are zero.

The Text PG loss converges to near zero after step 25, indicating the policy is already near-deterministic — it has found a single high-reward template and exploits it. MLP's large negative PG loss reflects the optimizer pushing hard on multimodal parameters but unable to improve the LLM's generation format.

7. Gradient Flow Diagnosis

This is the root cause of MLP's poor format compliance:

GradientTextMLP
grad_norm_lora0.4765.8e-10 ≈ 0
grad_norm_multimodal0.00.247
MLP LoRA gradients are zero

The joint gradient clipping (max_grad_norm=1.0) clips LoRA and multimodal parameters together. The multimodal parameters (pooling + projector, ~30M params with 5x learning rate) dominate the gradient norm, causing LoRA gradients to be effectively zeroed. The LLM's LoRA weights cannot learn to format outputs.

Why this matters

In the MLP approach, GRPO rewards flow backward through:

  1. LLM output tokens → LoRA weights (controls format, vocabulary, reasoning)
  2. LLM input embeddings → Projector → Pooling (controls protein representation)

With joint clipping, path (2) consumes the entire gradient budget. Path (1) gets nothing. The projector learns better protein representations (grad_mm = 0.247), but the LLM cannot learn to use them in the correct output format.

For Text, there are no multimodal parameters, so all gradient flows through LoRA — enabling format learning, vocabulary adaptation, and (unfortunately) template memorization.

8. Interpretation

What this experiment reveals

  1. Reward hacking via template copying: The Text model discovers that a single template ("Strong hydrophobic core...high confidence") achieves consistently high reward because most proteins in the dataset are well-folded. It optimizes for this shortcut rather than genuine protein analysis.
  2. Multimodal GRPO needs separate gradient clipping: Joint clipping of LoRA + multimodal parameters is catastrophic for the MLP path. The multimodal parameters monopolize gradient budget, starving LoRA of learning signal.
  3. Format compliance is a LoRA-level skill: Generating <answer>...</answer> tags is fundamentally a text generation capability. It requires LoRA updates. When LoRA can't learn (grad ≈ 0), format compliance stays at the SFT baseline (~74%).
  4. Higher reward ≠ better model: Text's 0.83 reward reflects exploitation of a distributional prior (most proteins are well-folded), not protein understanding. MLP's 0.58 reward with original reasoning is arguably more valuable scientifically.

The structural reward's vulnerability

The ESMFold reward uses four components: quality_alignment (text description matching), numerical_accuracy (pLDDT prediction), category_match (high/medium/low), and format_bonus. All four can be partially gamed by predicting "high quality" with pLDDT ~87 for every protein:

  • quality_alignment: "well-folded with high confidence" matches the ground truth for ~70% of proteins
  • numerical_accuracy: pLDDT ~87 is within 10 points of the actual value for most well-folded proteins
  • category_match: "high" is the mode category in the dataset
  • format_bonus: a fixed template always gets this right

9. Next Steps

  1. Separate gradient clipping: Clip LoRA and multimodal parameter groups independently with separate max_grad_norm values. This is the critical fix for MLP GRPO.
  2. Harder reward function: Add penalties for repeated/templated reasoning, require protein-specific features in the explanation, or weight the reward by dataset difficulty (down-weight easy well-folded proteins).
  3. Calibration reward: Penalize models that predict the same category/pLDDT for all proteins. Add a diversity term or calibration metric.
  4. Two-phase GRPO for MLP: Phase 1: freeze multimodal, train LoRA only (learn format). Phase 2: train both with separate clipping.
  5. Longer training with fixed gradients: Rerun MLP with the gradient fix to see if protein-aware reasoning can also achieve high reward when format compliance is not a bottleneck.
