1. GRPO Overview

Group Relative Policy Optimization (GRPO) is our reinforcement learning method for post-SFT alignment. Unlike PPO, GRPO requires no critic/value model. Instead, it generates a group of completions per prompt, scores each with a verifiable reward function, and computes advantages within the group.

Why verifiable rewards? Protein tasks have objectively correct answers (GO terms, ddG values, pLDDT scores, multiple-choice answers). We compute rewards by comparing model output to ground truth—no reward model needed.

For each prompt, GRPO:

  1. Generates group_size (8) completions via sampling
  2. Scores each with the task-specific reward function
  3. Computes group-relative advantages: A_i = r_i - mean(r_group)
  4. Updates policy to increase probability of high-advantage completions

2. SFT → GRPO Pipeline

Both GRPO experiments chain from the same MLP SFT checkpoint, creating a two-stage training pipeline:

Qwen3-8B + ESM-3 (frozen) + MLP Projector + LoRA

↓
Checkpoint: sft_esm3_mlp_combined_qwen3_8b_it_0306_010408

ESMFold reward (10K proteins)   |   MC accuracy reward (944 questions)

The parent_experiment field in each config points to the SFT checkpoint. The trainer automatically loads the SFT model (LLM + LoRA adapter + projector + pooling) and continues training with GRPO on the task-specific dataset.

3. Task 1: Structure Quality (ESMFold Reward)

Data Source

10,000 protein sequences with pre-computed pLDDT scores from AlphaFold DB. Each protein is classified as high (pLDDT > 80), medium (50–80), or low (< 50) quality. The protein sequence is the input field (fed through ESM-3 encoder), and the model must generate a natural language structural quality assessment.

python scripts/data/download_structure_quality.py --source alphafold --max_samples 10000

GROUND TRUTH

HYPOTHETICAL BAD RESPONSE

  • Quality alignment (0.0/0.4): Claims "well-folded" but pLDDT = 42.8 < 50 → wrong claim
  • Numerical accuracy (0.0/0.3): Predicted 75, true 42.8, error = 32.2 → 0.3 × exp(-32.2² / 200) ≈ 0.0
  • Category match (0.0/0.3): No "low quality"/"low confidence"/"poor" terms found

Reward Function Details

The ESMFold reward (compute_esmfold_reward in src/training/rewards.py) supports two modes:

ModeHow pLDDT Is ObtainedUse Case
Pre-computed JSON metadata: {"plddt": 88.4, "ptm": 0.0} Training with AlphaFold DB data (instant, no GPU overhead)
Live ESMFold Folds input sequence with ESMFold model Novel proteins without pre-computed scores

The numerical accuracy uses a Gaussian decay: reward = 0.3 × exp(-error² / (2 × 10²)), where error = |predicted_pLDDT - true_pLDDT|. An error of 5 points gives ~0.30, 10 points gives ~0.28, and 20 points gives ~0.24.

4. Task 2: ProteinLM Bench (MC Accuracy Reward)

Data Source

944 multiple-choice questions from tsynbio/ProteinLMBench covering protein biology: enzyme catalysis, protein function, PTMs, subunit structure, disease involvement, and tissue specificity. Each question has 2–10 options with one correct answer.

Note: Text-only task. ProteinLMBench questions contain no protein sequences—they are pure text knowledge questions. The ESM-3 encoder is present for consistency with the SFT model but receives no protein input. 
python scripts/data/download_proteinlm_bench.py --max_samples 944

PROMPT

2) They use a catalytic triad (Ser-His-Asp) for nucleophilic catalysis
3) They use a thiol group for covalent catalysis

Answer with just the option number (e.g., "option 1").
GROUND TRUTH
option 2
MODEL RESPONSE (sampled)
option 2
REWARD: 1.0

Binary reward: predicted index (1) matches correct index (1) → 1.0

Example 2: Post-Translational Modification Question

PROMPT
What is the primary function of ubiquitination in protein regulation?

1) Protein folding assistance
2) Signal for proteasomal degradation
3) Membrane anchoring
4) Disulfide bond formation
5) Glycosylation

Answer with just the option number (e.g., "option 1").
GROUND TRUTH
option 2
HYPOTHETICAL WRONG RESPONSE
I think the answer is option 1, as ubiquitin acts as a chaperone.
REWARD: 0.0

Binary reward: predicted index (0) ≠ correct index (1) → 0.0

Reward Function Details

The ProteinLM Bench reward (compute_proteinlm_bench_reward) is simple binary accuracy:

def compute_proteinlm_bench_reward(generated_text, ground_truth):
    # Parse "option N" from ground truth
    correct_idx = parse_option_number(ground_truth)  # e.g., 1 (0-based)

    # Parse predicted answer from model output
    _, pred_idx = parse_mc_answer(generated_text, num_options=10)

    return 1.0 if (pred_idx >= 0 and pred_idx == correct_idx) else 0.0

The parser (parse_mc_answer in src/evaluation/proteinlm_bench.py) looks for patterns like "option 2", "2)", "(B)", "answer is 2", etc. If no answer can be parsed, reward is 0.0.

Why the differences?
  • Lower LR for ProteinLM Bench: The 944-question dataset is small; higher LR risks overfitting.
  • More epochs for ProteinLM Bench: Compensates for fewer samples—3 epochs × 944 ≈ 2,832 samples vs 1 epoch × 10,000.
  • Shorter max tokens for MC: Answers are just "option N"—no need for 256 tokens.
  • Lower temperature for MC: 0.8 produces more focused answers for a task with one correct option.

6. Running the Experiments

Step 1: Download Data

# Structure quality (AlphaFold DB, no GPU needed)
python scripts/data/download_structure_quality.py --source alphafold --max_samples 10000

# ProteinLM Bench (HuggingFace)
python scripts/data/download_proteinlm_bench.py

Step 2: Ensure SFT Checkpoint Exists

# The parent experiment must exist in results/
ls results/sft_esm3_mlp_combined_qwen3_8b_it_0306_010408/checkpoints/protein_llm/

Step 3: Launch GRPO

# Structure Quality GRPO
python scripts/train.py main_RL=grpo_structure_mlp_sft

# ProteinLM Bench GRPO
python scripts/train.py main_RL=grpo_proteinlm_mlp_sft

Step 4: Monitor & Evaluate

# Watch on wandb (tags: grpo, structure_quality or proteinlm_bench)
# Key metrics: mean_reward, reward_std, policy_loss

# Evaluate after training
python scripts/evaluate.py experiment_name=grpo_structure_mlp_sft_... evaluation.name=all
GRPO Advantage Both tasks use verifiable rewards—no reward model to train or maintain. The structure quality task tests whether RL can improve numerical precision (pLDDT estimates) and factual consistency (quality claims). The ProteinLM Bench task tests whether RL can improve protein knowledge accuracy on established benchmarks.
