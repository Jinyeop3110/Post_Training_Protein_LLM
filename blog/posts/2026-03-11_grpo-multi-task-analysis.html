GRPO Multi-Task Analysis: ProteinLM-Bench vs Structure Quality

Date: 2026-03-11 | Tags: grporltrainingmilestone
Parent SFT: sft_esm3_mlp_combined_qwen3_8b_it_0306 (checkpoint-9750, eval_loss=0.361)

Executive Summary

Five GRPO runs completed from the MLP SFT checkpoint across two tasks. ProteinLM-Bench (v1: mean_reward=0.695, v2: mean_reward=0.676) shows consistent reward but suffers from 37-42% zero-std batches and very short completions (9-13 tokens). Structure Quality (mean_reward=0.780, pLDDT=80.19) achieves higher absolute reward with 0% zero-std batches, but LoRA grad norms are near-zero (4.9e-10), indicating the model is not actually learning from the structure signal. Both tasks reveal distinct failure modes that need targeted fixes before GRPO can improve over SFT.

Pipeline Overview

All GRPO runs chain from the same parent:

  • Parent SFT: sft_esm3_mlp_combined_qwen3_8b_it_0306_010408
  • Parent checkpoint: checkpoint-9750 (eval_loss=0.361, 9750 steps, 1.03 epochs)
  • Architecture: ESM-3 (frozen) + MLP projector + Qwen3-8B (LoRA r=8)
  • GRPO config: lr=2e-6, projector_lr=1e-5, clip_range=0.2, temperature=0.9, KL disabled

Key Issue: Zero-std fraction rising. 37.2% (v1) to 42.3% (v2) of batches have identical rewards within a group, providing zero learning signal. With group_size=8 and short completions (~9 tokens), the model collapses to a narrow set of nearly-identical outputs per prompt. Running 9 epochs (v2) worsened this compared to 2 epochs (v1).

Interpretation

  • Mean reward is stable at ~0.68-0.69 across both runs, suggesting the SFT checkpoint already produces reasonable index predictions.
  • Completions are extremely short (9-13 tokens). The model likely outputs only a number or short phrase and stops. With max_new_tokens=128, this means early EOS.
  • correct_index improved from 2.23 to 2.34, but predicted_index dropped from 2.24 to 2.16, meaning the model got slightly worse at matching the correct index while the average correct index shifted.
  • Format bonus is low (7-8%), indicating most completions fail the format check.
  • LoRA gradients are nonzero (0.39-0.40), so the model IS receiving gradient signal, unlike the structure task.

Good: Zero-std fraction is 0%. With group_size=16 and completions of exactly 32 tokens, every batch has reward variance. The structure reward function provides much better learning signal diversity than the index prediction task.
Critical Issue: LoRA grad_norm = 4.93e-10. Despite nonzero reward variance and nonzero pg_loss (-0.008), the LoRA parameters are receiving essentially zero gradient. The multimodal grad_norm is exactly 1.0 (clipped), but the LoRA parameters are frozen in effect. This means GRPO is not actually updating the language model for this task.

Interpretation

  • pLDDT = 80.19 indicates the input proteins are moderately well-folded. The model predicts pLDDT = 91.40, consistently overestimating by ~11 points.
  • quality_alignment = 0.354: the model's qualitative assessment (e.g., "good", "excellent") only partially matches the actual quality category.
  • numerical_accuracy = 0.162: predicted pLDDT numbers are inaccurate (mean absolute error ~11 points).
  • Fixed 32-token completions: all completions are exactly 32 tokens, suggesting max_new_tokens was set low or the model is producing fixed-length outputs. Training_args shows max_new_tokens=256, so the model is choosing to stop at 32.
  • The LoRA gradient problem is the most concerning finding. Possible causes: advantage normalization producing near-zero advantages (advantage_std = 0.033, vs 0.136 for proteinlm-bench), or the reward landscape being too flat relative to the policy gradient signal.

The two tasks fail in opposite ways: ProteinLM-Bench has LoRA gradients but too many zero-variance batches; Structure Quality has good reward variance but zero LoRA gradients.

Recommendations

  1. ProteinLM-Bench: increase group_size from 8 to 16 or 32. With only 8 completions per prompt and very short outputs (~9 tokens), groups collapse to identical outputs. Larger groups increase the chance of at least some variance.
  2. ProteinLM-Bench: increase max_new_tokens and add length-based reward. The model generates only 9 tokens. Encourage longer, more detailed responses with a minimum-length requirement in the reward function.
  3. Structure Quality: debug the LoRA gradient path. The advantage_std of 0.033 is 4x lower than proteinlm-bench (0.136). The near-zero LoRA gradients may stem from vanishing advantages after the policy gradient computation. Consider enabling advantage normalization or increasing group_size further.
  4. Structure Quality: investigate the 32-token fixed length. If the model always generates exactly 32 tokens, all variation comes from content, not stopping behavior. Check if this ceiling is limiting reward differentiation.
  5. Both tasks: enable KL penalty. Currently kl_coef=0.1 but use_kl_penalty=false. Without KL, the model can drift unconstrained from the SFT policy. Enable it with a small coefficient (0.01-0.05) to prevent degenerate mode collapse.
  6. Both tasks: run longer. v1 had only 39 steps (2 epochs), v2 had 130 steps (9 epochs). The structure run had 100 steps (1 epoch). Try 500+ steps with a warm-up schedule on the KL coefficient.
