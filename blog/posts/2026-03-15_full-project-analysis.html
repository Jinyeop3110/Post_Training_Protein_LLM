Full Project Analysis: 19 Experiments, 3 Approaches, 2 Training Stages

Date: 2026-03-15 | Scope: Complete inventory of all SFT and GRPO experiments | Model: Qwen3-8B + ESM-3

Executive Summary

Across 19 completed or in-progress experiments (4 SFT + 2 baselines + 13 GRPO), the ESM-3 MLP approach achieves the best SFT loss (eval_loss 0.361 vs Text-only 1.207, a 70.1% reduction) but Text-only achieves the best GRPO structure reward (0.832 vs MLP best 0.774). The core paradox of this project: lower perplexity does not translate to better downstream RL performance. The MLP gradient flow problem (LoRA grad_norm near zero during GRPO) remains the primary bottleneck for ESM-3 approaches in reinforcement learning.

3.2 The MLP GRPO Paradox

Core Paradox: MLP achieves 70% lower SFT loss but does NOT achieve better GRPO rewards. The best Text-only GRPO run (mean_reward 0.832) outperforms the best MLP GRPO run (0.780) by 6.7%. This reversal is caused by the LoRA gradient flow problem in the MLP approach.

3.3 Gradient Flow Analysis

Approach LoRA grad_norm Multimodal grad_norm Interpretation
Text-only (all runs) 0.25 - 0.49 0.0 (no MM params) Healthy gradient flow to LLM
MLP standard (0311_1142) ~0.0 (5e-10) 1.0 Gradients flow to MM only, LLM frozen
MLP long run (0312) ~0.0 (6e-10) 0.247 Gradients flow to MM only, LLM frozen
MLP frozen MM (0312) 0.071 0.0 (frozen) Small gradient to LLM (MM frozen)
MLP frozen + focal (0312) 0.119 0.0 (frozen) Better gradient to LLM with focal loss
ProteinLM MLP (both) 0.39 - 0.40 0.0 Healthy gradient (different task)
Key Insight: In MLP structure GRPO, the multimodal projector absorbs all gradients, leaving LoRA grad_norm at effectively zero. This prevents the LLM from learning format compliance and reasoning about structure. Freezing multimodal parameters partially restores LoRA gradient flow (0.071-0.119), enabling format learning but with lower reward magnitude.

Exception: ProteinLM-Bench GRPO shows healthy LoRA gradients (0.39-0.40) with zero MM gradients. This task (multiple-choice index prediction) may not require projector updates, allowing gradients to flow naturally to LoRA.

5. Key Findings

Finding 1: ESM-3 embeddings give a massive SFT advantage but not a GRPO advantage

SFT eval_loss: MLP 0.361 vs Text 1.207 (70% better). GRPO mean_reward: MLP best 0.780 vs Text best 0.832 (6.7% worse). The protein encoder helps the model understand protein properties for next-token prediction, but this advantage does not transfer to reinforcement learning on downstream tasks.

Finding 2: LoRA gradient blockage is the root cause

In MLP structure GRPO, LoRA grad_norm is effectively zero (5e-10). All gradients flow into the multimodal projector. This means the LLM weights cannot update during GRPO, preventing format learning and reasoning improvement. Freezing the multimodal parameters partially addresses this (LoRA grad 0.071-0.119) but the gradient magnitudes remain 4-7x smaller than Text-only's healthy 0.25-0.49 range.

Finding 3: SFT barely improves generation quality despite massive loss reduction

Despite 80x better eval_loss than baselines (0.361 vs 28.25 perplexity), BLEU only improves by ~85x (0.255 vs 0.003). More notably, MLP and Text-only achieve nearly identical BLEU (0.255 vs 0.254) despite a 3.3x eval_loss gap. The loss metric captures prediction accuracy on the full vocabulary, while BLEU measures n-gram overlap -- these are correlated but not linearly proportional.

Finding 4: Perceiver experiment never ran

The sft_esm3_perceiver_combined_0308 experiment has only an empty logs directory. The Perceiver Resampler (~29.4M params, comparable to MLP's ~30.5M) was never tested on the 4.89M dataset, leaving a gap in the four-way comparison (Text/MLP/Perceiver/Flamingo) that is central to the project thesis.

Finding 5: Classification GRPO underperforms standard GRPO

Binary classification variants (classify_mlp 0.598, classify_text 0.710) score lower than their standard counterparts (mlp 0.780, text 0.832). The classification format reduces the problem complexity but also limits the reward signal quality.

7. Recommendations and Next Steps

  1. Run the Perceiver SFT experiment: This is the most critical gap. The four-way comparison (Text/MLP/Perceiver/Flamingo) is the central thesis, and Perceiver remains untested. Priority: HIGH.
  2. Debug MLP LoRA gradient blockage: The zero LoRA gradient during GRPO is the root cause of MLP's underperformance. Investigate whether:
    • Gradient checkpointing or stop_gradient on the projector could help
    • Using separate optimizers for LoRA vs projector would prevent gradient absorption
    • Lowering projector_lr relative to LoRA LR during GRPO could rebalance gradient flow
    Priority: HIGH.
  3. Complete the thinking-mode SFT: At 500 steps, eval_loss was 0.613 -- promising but incomplete. Running to convergence would test whether chain-of-thought reasoning improves downstream GRPO performance. Priority: MEDIUM.
  4. Try GO prediction and stability GRPO tasks: All GRPO experiments so far focus on structure quality. GO prediction (functional annotation) and stability (ddG prediction) may show different MLP vs Text dynamics. Priority: MEDIUM.
  5. Investigate the BLEU plateau: MLP and Text-only achieve nearly identical BLEU despite 3.3x eval_loss gap. Qualitative analysis of generation examples may reveal whether MLP produces better-structured but differently-worded responses. Priority: LOW.
